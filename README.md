# The Eloquent Ear

The Eloquent Ear is a public-speaking training and presentation-support website
for founders, entrepreneurs, and startup teams. It helps clients communicate
their ideas with confidence through presentation preparation, proxy
representation, co-presenting, and public-speaking guidance.

The website is a static HTML, CSS, and JavaScript project. The final-improvement
homepage and its supporting assets are included directly in this repository.

## Features

- Premium presentation and public-speaking service pages.
- Three-stage service journey: representing, co-presenting, and elevating clients.
- Responsive desktop and mobile navigation.
- Pricing, frequently asked questions, legal information, and contact sections.
- Interactive booking and enquiry modals.
- Netlify-ready static deployment.

## Running locally

No build tools are required. Clone the repository and open `index.html` in a
browser, or serve the repository root with any static web server.
